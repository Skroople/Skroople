# Hi, I'm Skroople 👋

Computer Engineering student with a habit of opening things up to see how they work, and then making them work my way.

## 🔐 What I'm into

- **Offensive security**: working toward penetration testing, with a focus on **mobile** and **IoT / embedded** security
- **Device tinkering**: console homebrew (Wii, 3DS), iOS jailbreaking and sideloading, debloating smart TVs
- **Home lab**: Raspberry Pi systems, router firmware (OpenWrt), self-hosted services
- **Networking**: sockets, protocols, and how traffic actually moves
